Sécurité & Modification du mot de passe

Pour des raisons de haute sécurité, le mot de passe administrateur n'est jamais stocké en clair et ne transite pas par une interface non sécurisée.

Pour modifier votre mot de passe administrateur :

  1. Exécutez dans votre terminal local : npm run admin:hash-password
  2. Tapez votre nouveau mot de passe.
  3. Copiez la chaîne de hachage générée dans votre fichier .env.local (ou dans vos variables d'environnement Vercel) sous la clé ADMIN_PASSWORD_HASH.
